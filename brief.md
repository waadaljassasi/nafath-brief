## Overview
Technology is an important part of developing government services. An AI assistant can help people find information and get answers to their questions more easily. However, building a good assistant requires more than AI. Software engineering helps developers build and update the system. AI helps provide answers based on useful information. Mobile technology allows people to use the service through their phones, while networking keeps the system connected. Cybersecurity helps protect the system from attacks, and data management helps keep users’ information safe. All these fields work together to make the service more useful, secure, and reliable. In this mission, I will explore how these six IT fields support an AI assistant and why each field is important for providing better government services.
## Software
API versioning helps developers manage changes and update software without causing problems for existing applications. It also makes it easier to track changes and return to an earlier version if an issue occurs. There are three main types of version changes. MAJOR is used for changes that are not compatible with the previous version. MINOR is used when adding new features without breaking compatibility. PATCH is used to fix bugs without changing existing functionality. For example, adding a new feature to a government service requires a MINOR update if existing applications continue to work. This helps keep the service updated and reliable.

## AI
Retrieval-Augmented Generation (RAG) is a technique that helps AI provide answers using information from selected sources. First, the system searches for information related to the user’s question. Then, it gives the relevant information to the AI model to help it generate an answer. RAG can help reduce incorrect answers because the model has information to use instead of relying only on its existing knowledge. For example, a government assistant can search official service information before answering a citizen’s question. However, RAG does not guarantee that every answer is correct, so the information and sources should still be checked.

Source: Coursiv – https://coursiv.io/blog/what-is-rag-in-ai
## Mobile
Mobile applications should use secure network connections when sending information to a server. HTTPS helps protect data while it travels between the application and the server by using TLS encryption. This helps reduce the risk of attackers reading or changing the data during communication. For example, a government mobile application should protect citizens’ information when they ask an AI assistant about a service. Developers should avoid insecure connections and follow Apple’s security recommendations to help keep the application and its users safe.

Source: Apple Developer Documentation – https://developer.apple.com/documentation/security/preventing-insecure-network-connections
## Networking
IPv4 and IPv6 are two versions of the Internet Protocol used to identify devices and help them communicate over networks. IPv4 uses 32-bit addresses and can provide about 4.3 billion unique addresses. IPv6 uses 128-bit addresses and provides a much larger number of addresses. IPv6 was developed because the number of internet-connected devices increased and IPv4 addresses became limited. For example, smartphones, computers, and smart devices need IP addresses to communicate. Both protocols are important for network communication, but IPv6 supports a much larger number of devices.

Source: Coursera – https://www.coursera.org/articles/ipv4-vs-ipv6
## Cybersecurity
Prompt injection is a security risk that happens when someone tries to make an AI system follow harmful instructions instead of its original task. These instructions may come from a user or be hidden in a webpage or document. For example, an attacker may try to make a government AI assistant provide incorrect information or reveal private data. Developers can reduce this risk by limiting access to sensitive information, checking actions, and testing the system regularly.

Source: Coursiv – https://coursiv.io/blog/what-is-prompt-injection
